## Accessing and Running Individual Labs

Each lab assignment is organized into its own directory at the root level of this repository:

1. **Navigate to the desired lab folder:**
   ```bash
   cd Lab<Number>_<ProjectName>
   ```
2. **Review Lab Documentation:**
   Each lab directory includes its own local `README.md` or assignment documentation explaining specific requirements, setup steps, and environment prerequisites.
3. **Run or Test Projects:**
   - For Python scripts/tests (Labs 2, 5, 6, 7): Ensure Python 3.x is installed, set up a virtual environment if needed, and execute scripts or pytest runner as indicated in the respective subfolder.
   - For DVC / MLflow projects (Labs 3, 4): Review `.dvc` tracking files and MLflow configurations.
